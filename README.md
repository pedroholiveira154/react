# FilaZero

O **atv-simples** é um site institucional desenvolvido com o objetivo de apresentar e divulgar o projeto real FilaZero, um sistema de autoatendimento voltado para cantinas escolares, inspirado nos totens utilizados em redes de fast-food.

Este site não corresponde ao sistema de autoatendimento em si. Sua finalidade é exclusivamente informativa, apresentando a proposta, os objetivos, as funcionalidades planejadas e as características do projeto real.

## Objetivo

Apresentar como o FilaZero busca tornar o atendimento em cantinas mais prático e organizado, oferecendo uma alternativa para melhorar a experiência de compra e contribuir para a redução de filas.

## Tecnologias utilizadas nesse site

- React
- JavaScript
- HTML5
- CSS3
- Bootstrap
- React Router DOM

**FilaZero — Mais praticidade no atendimento da cantina.**
